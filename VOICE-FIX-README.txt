POCKET GAMEBOX v18 — Voice Playback Repair

Open index.html, select a game and press the visible 🔊 Voice button in the top bar.
Voice is enabled by default for new installations, unless previously muted. The button overrides mute when explicitly pressed.
Game voice samples are bundled locally, so they work without an internet connection.
Creative Claw streaming voices were replaced by the existing LOCAL fallback WAV files for reliability. These files are not the new Creative Claw performances.
On Android/iOS, audio needs a user tap first.
If your browser shows the older version, use a fresh folder or clear the website cache.
