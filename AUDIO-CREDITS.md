# Pocket Gamebox — locally bundled original Creative Claw music

The owner's eight original instrumentals are now stored in `assets/audio/`: one `music-lobby.mp3` for the collection and seven `music-<game>.mp3` tracks. Both the standalone game pages and the multiplayer TV page use these relative local files. All existing game effects and voice recordings remain unchanged. Original source URLs and keys are documented in `CREATIVE-CLAW-AUDIO-SOURCES.json` for provenance only, never accessed by running games. If a local track is unavailable the existing silence/error behaviour remains, with no remote fallback.
