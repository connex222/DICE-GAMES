POCKET GAMEBOX — PREMIUM EDITION v2.0

WHAT CHANGED
- Completely redesigned premium collection lobby and seven distinct typographic game identities.
- Shared premium styling applied to all seven game interfaces without changing game rules.
- Premium navigation treatment, accessible focus states and responsive layouts.
- Two ORIGINAL synthesized audio effects: UI selection and entry.
- Opt-in lobby spoken welcome via device speech synthesis (voice quality varies by browser and device).
- Shared optional interface click sounds; respects the lobby sound setting.
- Offline service worker cache version bumped, with new assets included.

WHAT HAS NOT CHANGED
- Gameplay logic, game scoring, player limits, data storage and persistence.
- This is NOT a fully recorded professional voiceover set; use recorded assets for a later voice pack.
- Online multiplayer is NOT included.

START
Extract the ZIP, open index.html in a browser. For PWA installation and reliable offline caching, serve over localhost or HTTPS.
Windows example: if Python is installed, open a terminal in the extracted folder and run: python -m http.server 8000
Then visit: http://localhost:8000

TESTING
Choose each of seven games, start a round, use in-game controls, return to lobby. Check phone and tablet widths and sound toggle. Gameplay test outcomes require browser-level verification.
