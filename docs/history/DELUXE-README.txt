POCKET GAMEBOX v2.1 DELUXE COLLECTION

Open index.html for direct offline play in a browser. For installable PWA/offline caching, serve over localhost or HTTPS.

WHAT CHANGED
- Custom scalable vector illustrations for all seven games and a unified logo.
- Audio button cycles OFF -> EFFECTS -> VOICE + FX (click to unlock audio).
- Eight individually authored offline British synthetic narration clips; generated with eSpeak and not a professional actor recording.
- Four new synthesized interface cues.
- Voice replay button in the game toolbar.
- Offline service-worker cache updated.
- Original gameplay scripts, scoring and save logic left unchanged.

LIMITS
- This update does not implement real multiplayer between phones.
- Full human playtest and visual QA across devices are still needed.
- Browser audio playback is user gesture dependent.
- Old service-worker cache may need a refresh after upgrading.
