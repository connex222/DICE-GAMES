POCKET GAMEBOX — CINEMATIC LOBBY REBUILD

Open index.html to launch. Desktop lobby deliberately uses the supplied cinematic concept artwork as the actual interactive backdrop, not a loose approximation. Click any illuminated game card. Mobile uses individually cropped concept cards.

All seven original game engines are preserved. The supplied image also depicts conceptual gameplay interfaces: those are NOT implemented as exact running game UI in this release. They would require separate game-by-game redevelopment and QA. No fake achievements or online multiplayer have been added.

To avoid a stale service-worker cache, run from a fresh folder and refresh the browser.
