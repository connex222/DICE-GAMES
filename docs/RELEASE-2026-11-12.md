## Deployment and limits
Owner approved merge/deploy on 12 November 2026. GitHub Pages publishes from main; this release requires no additional Render instance. The GitHub Pages build/public URL must be checked after the merge; GitHub Actions game tests alone cannot prove that the CDN has published the merge.

**Known acceptance risks:** physical iOS Safari/Android Chrome audio hearing and real-device handling untested; alternate rule modes/multiplayer and device interruption cases are not exhaustively covered. Existing game saves are browser-local. No unsupported claim of production-grade certification is made.

For local Windows ZIP installs, existing original alpha installation notes remain in docs/ALPHA-NOTES.md. Pull the latest main branch before generating any replacement ZIP.
